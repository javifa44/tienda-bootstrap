## Descripción

Este proyecto consiste en la maquetación visual de la página principal de una tienda online. Fue desarrollado con HTML5, Bootstrap 5.3.8 y una hoja de estilos CSS adicional.

## Componentes utilizados

- Container, Row y columnas responsivas.
- Carousel de Bootstrap.
- Cards para presentar los productos.
- List Group para el menú de categorías.
- Buttons para simular la opción de agregar productos.
- Badge para el contador visual del carrito.
- Bootstrap Icons.
- Footer con los datos del estudiante.

## Diseño responsivo

- En teléfonos, cada producto ocupa el 100% del ancho.
- En pantallas medianas y grandes se muestran tres productos por fila.
- El contenido principal utiliza `col-sm-3` para las categorías y `col-sm-9` para los productos.

## Archivos

- `index.html`: estructura principal de la página.
- `styles.css`: estilos adicionales.
- `README.md`: información del proyecto.

## Ejecución

Abre el archivo `index.html` en un navegador web. También puede utilizarse la extensión Live Server de Visual Studio Code.
